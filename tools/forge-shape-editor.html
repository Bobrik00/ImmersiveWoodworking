Холст (вид сверху)

кисть высоты:

ЛКМ / тянуть — ставит высоту кисти · ПКМ / тянуть — стирает (0) · колесо над клеткой — ±1.
Высота = число вокселей в колонке (0-6). Столбец с высотой 0 = сквозная проушина.
